## Project contributions and credits

### Sentrix

Jointly developed by **Haziq Afzal and Ruveeha Ashfaq** under HR-Presents. Both founders contribute across planning, design, implementation, testing, troubleshooting, documentation and release preparation.

Python security and quality analysis using Bandit, Pylint, Radon and Black, plus syntax validation and structured reporting. Security-framework references provide context rather than proof of compliance.

[Source repository — private](https://github.com/HR-Presents/HR-Presents-Sentrix)

### AegisLog

Jointly developed by **Haziq Afzal and Ruveeha Ashfaq** under HR-Presents.

Read-only defensive investigation of supported local logs, native telemetry and live streams. Features described on LinkedIn include deterministic rules, authentication correlation, incident grouping, evidence review and local HTML reports. Supported collectors include accessible Windows Event Logs, Linux journald and Docker logs.

The listed v2.1.17 release includes Windows downloads, a Python wheel and SHA256 checksums.

[Repository](https://github.com/HR-Presents/AegisLog) · [v2.1.17 release](https://github.com/HR-Presents/AegisLog/releases/tag/v2.1.17)

### AquaVigil

Developed collaboratively by **Haziq Afzal and Ruveeha Ashfaq**. The repository identifies Haziq as project author and Ruveeha as a contributor.

Read-only educational water and desalination evidence analysis with Python, Flask and Docker Compose. Supported evidence validation, SHA256 provenance, cyber/process correlation, findings and reports are complemented by Prometheus and Grafana observability. Findings require human review; the application does not control industrial infrastructure.

[Repository and documentation](https://github.com/HaziqBinAfzal/AquaVigil) · [v1.0.0 release](https://github.com/HaziqBinAfzal/AquaVigil/releases/tag/v1.0.0)

### Enterprise Linux Backup & Recovery System

Developed by **Haziq Afzal, Ruveeha Ashfaq, Ambreen Imtiaz and Muhammad Buddha**.

Documented stages include rsync backup, tar compression, GPG encryption, SHA256 verification, SSH transfer, cron scheduling and restoration testing. Repository screenshots provide evidence of the workflow.

[Repository and evidence](https://github.com/HaziqBinAfzal/linux-backup-recovery-system)

### SFVDS — Simple File Version Detection System

Developed by **Haziq Afzal, Ruveeha Ashfaq and Ambreen Imtiaz**.

Bash/Linux file versioning and monitoring using SHA256 and inotifywait, with backups, version tracking, change detection, rollback and logging. Consult the repository for watch, backup and rollback commands and supporting screenshots.

[Repository](https://github.com/HaziqBinAfzal/sfvds)
